# YASB Custom Configuration

A highly customized, CSS-styled configuration for [YASB (Yet Another Status Bar)](https://github.com/amnweb/yasb). This setup provides a clean, tailored desktop status bar for Windows, integrating seamlessly with tiling window managers like Komorebi. Also keep in mind this is my setup and you can modified wherever you want

## Features

* **Custom CSS Styling:** Deeply modified widget appearance, including seamless padding adjustments and hidden backgrounds for a floating effect.
* **Tiling Window Manager Integration:** Full support for Komorebi workspaces and active window tracking.
* **Nerd Font Implementation:** Uses MesloLGM Nerd Font for precise, clean iconography (including custom battery and charging states).
* **Smart Notifications:** Clean notification widget that automatically hides when empty to maintain a minimalist aesthetic.

## Prerequisites

Before installing this configuration, ensure you have the following installed:

1. **YASB:** The core application.
2. **Komorebi:** (Optional, but recommended) For workspace management.
3. **MesloLGM Nerd Font:** Required to properly render all icons (battery, notifications, workspaces).
